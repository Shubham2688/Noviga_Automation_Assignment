3. How Shifts Work

Key rule: shift_timings is a list of shift START times in IST — not start/end pairs. Each entry starts a shift until the next entry. The last wraps to the first.

Backend Response Example

{ "name": "summer-shift", "shift_timings": ["08:30", "19:00"] }

Two Shifts Parsed from Above

Dropdown LabelIST Window (Date = 23 Jun)UTC API Request
summer-shift (08:30 – 19:00) 23 Jun 08:30 → 23 Jun 19:00 03:00Z → 13:30Z
summer-shift (19:00 – 08:30 next day) 23 Jun 19:00 → 24 Jun 08:30 13:30Z → 03:00Z (+1 day)
Visual — Day Shift vs Night Shift (23 June 2026)
Important: The blue info banner in the app shows the exact IST and UTC window sent to the API. Always verify this matches your selected shift before interpreting data.

  • Precomputed marker positions in typed arrays
  • Pixel-bin downsampling when zoomed out — FAIL markers never dropped

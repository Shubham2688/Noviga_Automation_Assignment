1. What the application does

Production Timeline is a web dashboard for reviewing one machine (or line), for one shift, on one date. It combines a visual timeline of machine state and production with an hourly numeric summary.

Secure access Sign in with your account. Your session is restored if you refresh the page.
Timeline chart See runtime, downtime, stoppages, and PASS/FAIL production over the shift.
Hourly table Nine metrics broken down by clock hour — totals, minutes, and cycle times.

What you can do

  • Choose a machine / line, shift, and date
  • Switch between hourly overview and individual produce markers
  • Zoom into a time range by dragging on the chart
  • Hover markers for timestamp and PASS/FAIL detail
  • Refresh data without leaving the page
  • Sign out securely from the header menu
Scope note. This release focuses on a single machine + shift + date view. CSV/PDF export, auto-refresh polling, and multi-machine comparison are not included.

2. Getting started — sign in

  1. Open the application URL in a modern browser (Chrome, Edge, or Firefox recommended).
  2. On the login screen, enter your username and password.
  3. Click Sign in. On success you are taken to the Production Timeline dashboard.
  4. To leave the app, click your name in the top-right → Logout.

Session behaviour

SituationWhat happens
You refresh the browser You stay signed in (session is restored and validated).
Session expires or token is rejected You are returned to the login page with a clear message.
Wrong username or password Message: Incorrect username or password. Please try again.
Empty fields Message: Username and password are required.

4. Using the filter bar

Machine / Line

Pick the asset you want to inspect. The list is hierarchical (indented lines and machines). By default the first available machine-level asset is selected.

Shift

Shifts come from the backend (they are not hard-coded). Labels show the IST start–end window. Overnight shifts are labelled with next day so the calendar date you pick is unambiguous.

Example labelMeaning
08:30 – 19:00 Same calendar day, day shift window.
19:00 – 08:30 next day Starts on the selected date at 19:00 IST; ends the following morning at 08:30 IST.

Date

Choose the production date in IST. For the current demo environment, available sample data is limited to 22–25 June 2026.

Show individual produces

ToggleChart behaviour
OFF (default overview) One summary marker per shift hour with hourly pass counts and a cumulative production line — easier for a quick scan.
ON (detail) Every produce event as its own marker: blue = PASS, red × = FAIL, at the real timestamp.

Refresh

Click the circular refresh icon to reload the latest intervals and cycle-time data for the current filters.

5. Reading the timeline chart

The chart is titled Production History. Colour bands show machine state; markers show production.

Machine state colours

ColourStateMeaning
Teal / green Runtime Planned productive running time.
Olive Unplanned Production Production outside the planned runtime classification.
Orange Unknown Downtime Downtime not yet classified.
Purple Stoppage Stoppage interval.

Production markers

  • Blue dot — PASS (good part)
  • Red circle with × — FAIL (NG part)
Machine state
Time axis (IST)
Shift start → hour ticks → shift end

Interactions

ActionResult
Drag horizontally on the chartZoom into that time range.
Double-click, or use Reset ZoomReturn to the full shift window.
Hover a markerSee timestamp and PASS/FAIL detail.
All times on the chart and in tooltips are shown in IST. The backend stores timestamps in UTC; conversion is handled automatically.

6. Hourly production & downtime summary

Below the chart, the table Hourly Production & Downtime Summary breaks the shift into clock-hour columns. Each row is a metric; each column is one hour overlapping the selected shift.

RowWhat it means
TotalPass + Fail count for that hour.
PassGood parts (ok_count).
FailNG parts (ng_count).
Runtime (min)Minutes of planned runtime in the hour.
Unplanned Production (min)Minutes of unplanned production.
Stoppage (min)Minutes of stoppage.
Unknown Downtime (min)Minutes of unclassified downtime.
Ideal Cycle Time (s)Target cycle time for the hour.
Actual Cycle Time (s)Measured cycle time for the hour.
In-progress shifts. For hours that have not occurred yet, cells are left blank (not filled with zeros) so the table does not look like “no production” when the hour simply has not started.

7. Common situations & messages

The application uses plain-language messages (no raw HTTP status codes in the UI).

What you seeWhat to do
Loading skeletons / busy chart Wait for the request to finish. Large individual-produce views may take a moment.
Empty chart / no data Try another date (22–25 Jun 2026 in demo), machine, or shift. Check the blue query-window banner.
“We could not find data for this selection…” Change date, machine, or shift, then retry.
“Your session has expired…” Sign in again.
“Unable to reach the server…” Check network connectivity and try Refresh.
“Something went wrong on our side…” Use the Retry button on the dashboard error panel.
Machine or shift list failed to load Refresh the page. If it persists, contact your administrator.

Suggested walkthrough for a client demo

  1. Sign in with the demo account.
  2. Select an AOI (or other machine-level) asset, a day shift, and date 23 June 2026.
  3. Review the colour bands and hourly table with the toggle OFF.
  4. Turn Show individual produces ON and hover a few PASS/FAIL markers.
  5. Drag to zoom a busy hour, then reset zoom.
  6. Switch to an overnight shift labelled “next day” and confirm the query-window banner.

9. Quick reference checklist

Before you start Browser ready · credentials available · know which machine and shift to inspect.
Pick the window Machine / Line → Shift → Date. Confirm the blue IST query window.
Overview vs detail Toggle OFF for hourly overview; ON for every produce marker.
Explore time Drag to zoom · hover for detail · Reset Zoom to go back.
Read the numbers Use the nine-row hourly table for counts, minutes, and cycle times.
When stuck Refresh · Retry · change date (22–25 Jun 2026 in demo) · sign in again if session expired.
